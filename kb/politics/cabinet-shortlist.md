# Cabinet shortlist

*Not announced. The list has been "final" since March and has been amended nine
times. Names are withheld pending their agreement, their disagreement, or their
finding out.*

| Portfolio | Status | Note |
| --- | --- | --- |
| Minister for Making Sure | confirmed | the only confirmed appointment |
| Minister for Second Opinions | pending | refused, then un-refused, then refused |
| Under-Secretary for Continuity | vacant | the previous holder was unaware of the post |
| Minister for the Bridge | proposed | two candidates, neither from the district |
| Minister for Enthusiastic Agreement | proposed | the name was too good to waste |
| Minister for Saying Nothing | proposed | the ideal candidate is on record saying something |

## Notes

- The Minister for Making Sure has asked for a deputy. There is no budget for a
  deputy; there is a budget for a plaque.
- The portfolio "Minister for the Bridge" conflicts with the existing portfolio
  "Minister for Bridges", which was created by mistake and has since acquired
  responsibilities.
- An eleventh portfolio, "Minister for Other Things", was proposed in a taxi and
  is not in the table above because nobody wrote it down.
